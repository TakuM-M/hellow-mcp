Pi Home MCP Design

Run an MCP server on the Raspberry Pi at home so that Claude can safely work with the home server and its sensors. This page is a visual overview to help understand the design, and it grows as decisions are made.

1System overview

Language: Python with FastMCP. The Pi's camera, GPIO and sensor libraries are best supported in Python, and language speed makes no noticeable difference here, since a tool call spends its time on Claude and the network. To stay ready for growth, each tool group lives in its own module, settings live in config.yaml, and the code uses type hints and tests. Because Claude only sees tool names and their inputs and outputs, any part can later be rewritten in another language such as Go without changing the Claude side.

4Security rules

  • Do not build a tool that runs arbitrary shell commands.
  • Action tools only affect targets on the allowlist in config.yaml.
  • Run the MCP server as the dedicated low-privilege user mcp. Add only the permissions Docker operations need.
  • Start with read-only tools, then add action tools one at a time.
  • Never expose the server to the internet without authentication. Build ③ only after OAuth is in place.

5Roadmap

  1. PHASE 0
    Build a skeleton on your PC DoneWithout a Pi, build a FastMCP server with get_system_status and confirm Claude Desktop / Code can call it.
  2. PHASE 1
    Move it to the Pi and connect over SSH NextSet up Raspberry Pi OS and open route ① by starting the server over stdio, with no systemd needed.
  3. PHASE 2
    Add server management toolsDocker, logs, service state. Add action tools with an allowlist.
  4. PHASE 3
    Sensors, appliances and remote accessBME280, camera, Wake-on-LAN, SQLite. Switch to HTTP and use it from outside through Tailscale (②).
  5. PHASE 4
    Connect from claude.aiImplement OAuth and make it usable from a phone through Cloudflare Tunnel (③).

6Open questions

  • Raspberry Pi 4 memory and storageThe plan is to use the Pi 4 at home (model to be confirmed on the device). Memory size is unconfirmed. For always-on use, consider booting from a USB-connected SSD.
  • How to grant Docker permissionsThe docker group is effectively root. Compare it with allowing only specific commands through sudoers.
  • Appliance integrationChoose between the SwitchBot API, Nature Remo, or a homemade infrared module.
