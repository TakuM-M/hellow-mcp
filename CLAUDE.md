# CLAUDE.md

## Language

- Write `README.md`, `CLAUDE.md` and `architecture/index.html` in English.

## Design document

- `architecture/index.html` is a visual overview of the system design, meant to help the owner understand it.
- When making a design decision or change, update this HTML in the same change.
  - Rewrite the relevant sections (1 to 6).
  - When an open question in section 6 is decided, remove it from section 6 and reflect the decision in the relevant section.
  - Bump the version and the updated date in the header, and add one line to the changelog in section 7.
- Draw diagrams as inline SVG, using CSS variables for colors (supporting both light and dark themes). Do not use external images.
